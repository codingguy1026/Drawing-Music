# Drawing Music 🎧

**Drawing Music (드뮤직)** is the music space within the Drawing ecosystem.

This is an early functional prototype, not a licensed commercial music-streaming catalog. It includes an original, procedurally synthesized demo library so the player works without copying third-party recordings.

## Visual identity

Drawing Music is part of the Drawing ecosystem, **but owns a completely independent interface, palette, typography, visual motifs and player experience**. Cross-service entry points are integrations, not shared themes. Current visual style is a provisional music-first direction and can be refined.

## Features (prototype)
- Independent DMUSIC design (midnight charcoal, peach + aqua accents, handcrafted geometric album art), not a Drawing Verse or Spotify theme skin
- Collapsible desktop library navigation, persistent playback bar, and album-forward discovery
- One-tap mood-based demo playback, curated demo picks and recent-listening shortcuts
- Expanded Now Playing panel with upcoming queue, track information and interactive demo waveform visualization
- Play, pause, previous/next, shuffle, repeat, seek and volume
- Search and discover original demo tracks
- Local liked tracks, recent listening and user-created playlists (stored in this browser)
- Drawing Verse cross-service entry point via environment configuration
- Privacy-first groundwork for an optional, opt-in "now playing" activity card

## Benchmarking goals

- **Spotify:** Familiar library-first navigation and playback continuity.
- **Apple Music:** Spacious album-first presentation.
- **YouTube Music:** Expandable player, queue, and track metadata.
- **FLO:** One-tap mood listening.
- **Melon:** Curated discovery, labelled **demo picks**, never presented as a real chart.
- **SoundCloud:** A note-derived decorative waveform with seeking. This is **not** an actual sampled recording waveform.

All layouts, illustrations and demo sounds are DMUSIC originals, and the theme remains independent from Drawing Verse. The sample catalog contains no licensed commercial releases.

Read the [design-quality checklist](docs/design-quality.md) to see what has changed and which visual checks still require manual browser testing.

## Develop

Requires Node.js 20.9+ (Node 22 recommended).

```sh
npm install
npm run dev
```

Open http://localhost:3000

Copy `.env.example` to `.env.local` to set Drawing Verse's canonical URL if known. No secret key is necessary for this local demo.

```sh
npm run typecheck
npm run build
```

## Rights and safety
No copyrighted commercial audio is bundled. The demo tones and melodies are generated by the code here. Any public launch involving third-party music requires the necessary recording/composition rights and appropriate content moderation and account protections.

## 2025 × 2026: Taste Studio (November 2026)

The 2025 recommendation experiment is now adapted to the 2026 Classic home page. Its paper-and-glass cards coexist with the current independent player.

- Visit **For You** to tune BPM, energy, rhythm and brightness, or choose **New Discoveries** to prioritize unheard/unliked demo tracks.
- Recommendations now point to **real playable tracks in the current demo library**, not the mock titles from the 2025 archive.
- Hearts from the new recommendation cards update the existing local likes and gently shift your local taste profile.
- Scores use simple weighted distance over **editorial approximations of the demo tracks' mood/genre**, not real signal analysis, AI-generated recommendations or streaming analytics.
- Player, playlists, searches, local storage, theme and Drawing ID integration are untouched. The archived 2025 code remains under [`legacy/2025-12-26/`](legacy/2025-12-26/).

No third-party music is added. This remains a local demo prototype.

> Build note: the standalone archived 2025 project has its own dependencies and tsconfig. The root TypeScript project excludes `legacy/` so archived auth experiments never affect the current app's production build.


## Album-reactive immersive player

The persistent Classic player now exposes an **expand** button. It opens the existing Now Playing panel with a 2025-paper-glass-inspired album stage and per-track color palettes. Play/pause, previous/next, seek, queue, repeat, shuffle, like and Esc-to-close are wired into the same 2026 audio engine and browser-local library.

The glow is a hand-curated palette associated with demo artwork, **not** signal analysis or third-party album imagery. The decorative waveform is still based on procedural demo note data. Expand is reversible, closing it does not stop audio.

## Color Bloom visual refresh (November 2026)

The Classic homepage uses a brighter pastel palette (lilac, peach, mint) with a colorful album-art hero, glass navigation, more expressive discovery cards, and a tinted persistent playback bar. Dark mode retains its toggle but uses deep plum and emerald accents instead of flat charcoal. Playback, recommendations, likes, playlists, and account integration are unchanged. This is a CSS and markup redesign, not a new music catalog.

## Studio Hub: a real browsing structure

The modern Drawing Music homepage now includes a sticky desktop section rail, a recent-listening carousel/grid based on local history, 3 original album collections with expandable tracklists, and 3 ready-to-play themed mixes. Album and mix play actions create an **in-memory queue** so tracks advance within the selection, including the expanded player's visible upcoming queue. Starting an individual track returns to the full demo catalog sequence. Saved likes, searches, recommendations, playlists, the procedural audio engine, dark mode, and the Drawing ID integration remain in place.

The three releases and mixes are editorial groupings of the existing six original synthesized demos. They are not third-party albums, a commercial catalog, or a claim of real chart/streaming activity. Music discovery remains entirely client-side.

## Distinct screen navigation

The sidebar selects hash-addressable views for Home, Albums, Mixes, For You, Discovery, Library, Visualizer and Drawing Connection. Legacy hash aliases are supported, and mobile gets a horizontal menu. The audio engine remains mounted above the screen switching layer, preserving playback on navigation.

## Drawing ID public browser configuration fallback

The login modal requires a Supabase URL plus a publishable key. Some deployments were built without those browser environment variables and showed a "server not configured" message. The intended shared Drawing ID project's URL and **publishable, non-privileged** key were already present in `.env.example`, and the project's status and key were verified. The browser now falls back to those public values **only when both environment variables are absent**. If only one is provided, authentication fails closed rather than combining mismatched settings.

Configure BOTH `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in the deployed environment for production and key rotation. Never use any secret or service-role key in browser code. A **successful new deployment is still required** for this fix to appear on the website; it does not resolve Vercel deployment errors. Email confirmations and redirect allowlists must be configured in Supabase Auth for the verified production domain. A real user login was not tested by this code change.
